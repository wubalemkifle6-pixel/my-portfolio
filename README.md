# Developer Portfolio (React + Vite)

A responsive dark navy and blue portfolio starter for a Software Engineering student applying for internships.

## 1. Requirements
- Install Node.js (LTS) from https://nodejs.org/
- Install Visual Studio Code from https://code.visualstudio.com/

## 2. Run on Windows
Open this project folder in VS Code. Choose **Terminal → New Terminal**, then run:

```powershell
npm install
npm run dev
```

Open the local URL printed in the terminal, usually `http://localhost:5173`.

## 3. Customize before publishing
1. In `src/App.jsx`, edit the About Me paragraph and education details to be accurate.
2. Update the `projects` array with each real repository URL and accurate project status.
3. Replace the GitHub profile URL if your username changes.
4. Add your own email and CV link when ready. Do not publish private phone numbers unless you want them public.
5. Update skills to reflect what you can confidently discuss in an interview.
6. Add screenshots of your own projects when available.

## 4. Build for production
```powershell
npm run build
npm run preview
```

Vite creates the production website in the `dist` folder.

## Important
The project cards currently use your known GitHub profile for projects whose individual repository URLs were not provided. Replace those profile links with the correct repository URLs when available. The descriptions are starter copy; make sure they match the features you have actually implemented.
